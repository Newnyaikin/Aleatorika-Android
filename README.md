**Алеаторика** — приложение для развития музыкального слуха и практики на гитаре. Слушай ноты и аккорды, находи их на грифе или повторяй по схеме. Заниматься можно с гитарой и без неё.

## Возможности

- **На звук** — слушай образец и повторяй его на гитаре. В обучении можно продолжить и без проверки через микрофон.
- **По схеме** — смотри на ноту или аппликатуру и играй. Для аккордов доступны открытые формы, формы с баррэ или все вместе.
- **Без гитары** — находи услышанную ноту на интерактивном грифе или узнавай аккорд по рисунку. Микрофон не нужен.
- **Свой темп или игра на скорость** — выбирай обучение без таймера или тренировку на время с комбо и личными рекордами.
- **Удобные настройки** — светлая и тёмная темы, выбор диезов или бемолей и диапазона ладов в режиме грифа.
- **Нативное приложение** — Android-версия работает самостоятельно, без WebView и веб-сервера.

## Как начать

1. Открой [страницу релизов](../../releases) и скачай APK, если он там опубликован. Тестовая сборка также доступна в **Actions → запуск сборки → Artifacts**.
2. Установи APK на устройство с Android 8.0 или новее. При необходимости разреши установку приложений из выбранного источника в настройках Android.
3. Открой Алеаторику и выбери режим: **На звук**, **По схеме** или **Без гитары**.
4. Выбери **ноты или аккорды**, а затем обучение или игру на скорость. Для проверки игры разреши доступ к микрофону; наушники помогут уменьшить влияние звука образца.
5. Нажми **«Начать»** и занимайся в удобном темпе.

> [!NOTE]
> Распознавание аккордов находится в стадии бета-тестирования и может ошибаться. Проверяется звучание аккорда, а не положение пальцев. Аудио обрабатывается на устройстве, не записывается в файлы и не отправляется.

## Частые вопросы

**Можно ли пользоваться без гитары?**  
Да. В режиме **«Без гитары»** задания выполняются на экране — без инструмента и микрофона.

**Зачем нужен микрофон?**  
Он позволяет проверять игру на гитаре в соответствующих режимах. В обучении на звук можно продолжить и без автоматической проверки.

**Почему APK не устанавливается поверх предыдущего?**  
Тестовые сборки GitHub Actions могут подписываться разными ключами. Для постоянных обновлений настрой один ключ по [инструкции по подписи](docs/SIGNING.md). Удаление приложения также удалит локальную статистику — не делай этого, если она важна. APK с `-unsigned` нельзя установить до подписи.

**Где сохраняются настройки и рекорды?**  
На устройстве. При удалении приложения они удаляются.

**Можно ли заниматься в браузере?**  
Да, доступна отдельная [веб-версия Алеаторики](https://newnyaikin.github.io/Aleatorika-Web/).

## Сборка и разработка

Android-проект написан на Java. Для локальной сборки нужны **JDK 17** и **Android SDK 35**. Из корня проекта:

```bash
bash tools/build-apk.sh
```

Скрипт создаёт тестовый и неподписанный release APK в `dist/`. При настройке ключа подписи он также создаёт подписанный release APK. Папки `android/` и `shared/` должны оставаться рядом.

GitHub Actions собирает APK при отправке изменений в `main`, для pull request и при ручном запуске. Результат доступен в **Artifacts**. Тег вида `v*` запускает публикацию релиза; без настроенного постоянного ключа это тестовый pre-release. Автоматическая сборка не заменяет проверку приложения на устройстве.

Подробнее: [пошаговая инструкция](docs/START.md) · [постоянная подпись APK](docs/SIGNING.md)

В проект включён шрифт Manrope; его лицензия находится в [shared/Manrope-OFL.txt](shared/Manrope-OFL.txt).
